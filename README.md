# XAI – Intelligence Workspace

A modern AI-powered frontend product experience built for the RacoAI Frontend Challenge.

---

## 🚀 Project Overview

XAI – Intelligence Workspace demonstrates how raw business data can be transformed into structured intelligence through interactive visualizations, purposeful motion, and a clean, modern user interface.

The goal of this project was to create a polished product experience rather than a traditional marketing landing page.

---

## ✨ Features

- Responsive Layout
- Interactive Hero Section
- Smooth Scroll Navigation
- AI Workflow Visualization
- Dashboard Preview
- Signature AI Core Interaction
- Loading Screen
- Mobile Navigation
- Modern Glassmorphism UI
- Professional Dark Theme

---

## 🛠 Tech Stack

- React.js
- Vite
- Tailwind CSS
- Framer Motion
- React Icons
- Git & GitHub
- Vercel
- Figma

---

## 🎬 Motion & Interaction

This project uses Framer Motion to create smooth and meaningful animations, including:

- Hero entrance animation
- Cursor-based orb interaction
- Floating particles
- Infinite rotation effects
- Hover animations
- Smooth section navigation
- Responsive mobile menu animation

## ⚙️ Installation

Clone the repository

```bash
[git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git](https://github.com/abdurrahmantushar/Xai-frontend-abdur.git)
```

Go to the project directory

```bash
cd YOUR_REPOSITORY
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
